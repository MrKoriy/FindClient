# 2GIS Lead Scraper Bot

## What This Is

Telegram-бот для лидогенерации, который через 2GIS API ищет контакты организаций по выбранной нише в Москве и отдаёт результаты в CSV-файле. Личный инструмент для cold email и cold DM кампаний.

## Core Value

Быстрый сбор контактов бизнесов по нише в один клик — от выбора категории до готового CSV за минуту.

### Out of Scope

- Мультигород — пока только Москва, расширим позже
- Многопользовательский доступ — личный инструмент
- Автоматическая отправка cold email — бот только собирает контакты
- Веб-интерфейс — только Telegram
- Оплата / монетизация — личное использование

## Context

- 2GIS API ключ уже получен, будет храниться в .env
- Бот на Python (aiogram или python-telegram-bot)
- 2GIS API возвращает: название, адрес, телефоны, сайт, email, рейтинг, отзывы, соцсети
- Для хранения истории и дубль-фильтра нужна лёгкая БД (SQLite)
- Город поиска: Москва (захардкожен как дефолт)

## Constraints

- **API лимиты**: 2GIS API имеет ограничения по количеству запросов — нужна пагинация и обработка rate limits
- **Данные**: не все организации имеют email/сайт/соцсети — бот должен корректно обрабатывать отсутствующие поля
- **Telegram**: лимит на размер файла 50MB, но для CSV это не проблема
