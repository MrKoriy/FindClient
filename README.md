# FindClient

Telegram-бот, который ищет клиентов на сайты и лендинги:

| Раздел | Что делает | Источники |
|---|---|---|
| 🔎 Компании с карт | Любая ниша × любой город (от Москвы до Урюпинска), фильтры «без сайта» / «с телефоном», слияние дублей между источниками, скоринг, выгрузка в XLSX/CSV | 2GIS (подписанный JSON API сайта 2gis.ru, запасной путь — парсинг страниц), Яндекс Карты (официальный API по ключу или веб-режим без ключа) |
| 💰 Денежные ниши | 39 ниш с оборотом компаний от миллионов ₽ в месяц: средний чек, зачем им сайт, запросы для карт, профильные Telegram-чаты | `data/niches.py` |
| 👷 Telegram-лиды | Строители, прорабы, дизайнеры, риелторы, спецтехника: авторы сообщений из профильных чатов (имя, @username, телефон, био, пример сообщения, скоринг) | Telethon (аккаунт пользователя) или публичные каналы через t.me/s |
| 💼 Заказы с бирж | Автоматически присылает новые заказы на сайты по ключевым и минус-словам | Kwork, FL.ru, Freelance.ru, FreelanceJob, Telegram-каналы, «нужен сайт» в чатах (с аккаунтом) |
| 📨 Рассылки + CRM | Кампании с цепочкой (первое сообщение + 2 напоминания), A/B/C-варианты, демо-сайт под каждого лида, AI-персонализация, классификация ответов, воронка, CRM в Excel | ваши Telegram-аккаунты (Telethon), DeepSeek (B.AI), Jev (TypeSafe) |
| 🧠 Офферы | Разбирает видео/каналы/статьи креаторов в библиотеку приёмов и собирает ваш оффер под нишу | YouTube-субтитры, t.me, любые статьи, вставленный текст |

Уже собранные компании при повторном поиске пропускаются (по id и по телефону), а историю можно скачать заново.

## Запуск

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # впишите BOT_TOKEN и свой OWNER_IDS
python bot.py
```

Ваш Telegram ID бот покажет сам, если вас нет в `OWNER_IDS`.

### Переменные `.env`

| Переменная | Нужна | Описание |
|---|---|---|
| `BOT_TOKEN` | да | токен от @BotFather |
| `OWNER_IDS` | рекомендуется | ID пользователей через запятую; пусто — бот доступен всем |
| `YANDEX_API_KEY` | нет | ключ «API Поиска по организациям»; без него работает веб-режим |
| `HTTP_PROXY` | нет | прокси для Яндекса, если он начнёт показывать капчу |
| `TG_API_ID`, `TG_API_HASH`, `TG_SESSION` | нет | аккаунт Telegram для чтения групп (см. ниже) |
| `ORDERS_POLL_INTERVAL` | нет | период опроса бирж, секунды (по умолчанию 300) |
| `TG_SESSION_2` | нет | второй аккаунт для рассылок |
| `BAI_API_KEY`, `BAI_MODEL` | для AI | DeepSeek через B.AI (по умолчанию `DeepSeek-V4.1-Flash`) |
| `TYPESAFE_API_KEY` | нет | Jev для классификации |
| `DEMO_BASE_URL`, `WEB_PORT` | для демо-сайтов | публичный адрес сервера и порт (8080) |
| `OUTREACH_DAILY_MAX`, `OUTREACH_WORK_HOURS` | нет | максимум новых диалогов в день на аккаунт (20) и окно отправки (`10-19`) |

### Аккаунт Telegram (для групп строителей и поиска чатов)

Bot API не умеет читать чужие группы, поэтому для групп нужен пользовательский аккаунт:

1. Получите `api_id` и `api_hash` на https://my.telegram.org → API development tools.
2. `python scripts/tg_login.py`: введите телефон и код, скрипт напечатает `TG_SESSION=...`.
3. Добавьте три переменные в `.env` и перезапустите бота.

Используйте отдельный аккаунт. Чтение безопасно, а массовые рассылки из него быстро приводят к блокировке.
Без аккаунта раздел работает в урезанном режиме: собирает контакты из постов публичных каналов.

## Рассылки в Telegram

Поток работы: `/find ниша | город` → «📨 Добавить в рассылку» → кампания с оффером → «▶️ Запустить».
Бот сам пишет в рабочие часы, ведёт цепочку и останавливает её, как только человек ответил.
Ответы приходят вам в бот с меткой: 🔥 интересно, 💰 цена, ⏳ позже, 🙅 отказ, ⛔ не писать. Из карточки лида можно
ответить сразу со своего аккаунта, попросить у DeepSeek черновик и сменить статус (созвон, сделка, отказ).

**Лимиты и безопасность аккаунтов.** В Telegram главный риск — жалобы на спам от незнакомых людей. Поэтому бот:
- пишет только с ваших аккаунтов и только в будни 10:00–19:00 МСК, с паузами 4–12 минут между сообщениями;
- прогревает каждый аккаунт: 5 новых диалогов в первый день, дальше +3 за каждый активный день, максимум `OUTREACH_DAILY_MAX` (20);
- ищет аккаунт по номеру телефона не чаще 10 раз в день (импорт контактов — сильный спам-сигнал);
- при `PeerFlood` ставит аккаунт на паузу на сутки, при `FloodWait` — на указанное время, и сообщает вам;
- никогда не пишет одному человеку из двух кампаний; «не пишите» навсегда заносит человека в стоп-лист.

С двумя аккаунтами это примерно 10 новых диалогов в первый день и 40 в день через неделю. Больше Telegram без
жалоб не пропустит, поэтому бот делает ставку на качество: персонализацию, демо-сайт и короткое сообщение с
одним вопросом. Обходить лимиты фермами аккаунтов бот не будет.

**Демо-сайты.** Если задан `DEMO_BASE_URL`, для компаний с карт бот перед первым сообщением собирает лендинг
(DeepSeek пишет тексты, вёрстка готовая, адаптивная) и подставляет ссылку вместо `{demo_url}`. Сайты отдаёт
встроенный веб-сервер бота на `WEB_PORT`. Без домена откройте порт на VPS (`ufw allow 8080`) и укажите
`DEMO_BASE_URL=http://<IP>:8080`. Ссылки по IP выглядят хуже, поэтому, когда продлите домен, укажите его.

**AI.**
- `BAI_API_KEY` — DeepSeek-V4.1-Flash через B.AI (`https://api.b.ai/v1`): офферы, персонализация, черновики ответов, тексты демо-сайтов.
- `TYPESAFE_API_KEY` (необязательно) — Jev от TypeSafe: быстрая типизированная классификация ответов
  («интересно / цена / позже / отказ / не писать» с вероятностями), отсев вакансий из заказов и оценка,
  кто из авторов в Telegram-чатах — потенциальный заказчик. Без ключа классификацию делает DeepSeek, а без него — правила.

**Второй аккаунт:** запустите `python scripts/tg_login.py` ещё раз, войдите во второй номер и впишите сессию в `TG_SESSION_2`.

`/start` меню · `/scrape` поиск компаний · `/find стоматология | Казань | 100` быстрый поиск ·
`/niches` ниши · `/tg` Telegram-лиды · `/orders` заказы · `/outreach` рассылки · `/offers` офферы ·
`/history` · `/stats` · `/cancel`

## Ограничения

- **Avito**: блокирует серверные запросы (429), а официальный API не ищет чужие объявления. Рабочий путь — разместить своё объявление «Разработка сайтов» и подключить Messenger API (нужен бизнес-тариф). Не реализовано.
- **Хабр Фриланс** закрыт; **Weblancer** и **YouDo** закрыты антибот-защитой.
- Выручку компаний карты не отдают, поэтому «размер» бизнеса оценивается косвенно: по числу отзывов, филиалов и рейтингу (колонка «Скоринг»).
- Данные 2GIS и Яндекса предназначены для личного использования; не распространяйте выгрузки.

## Разработка

```bash
pytest -q
```

Структура: `api/` — клиенты источников, `services/` — бизнес-логика (поиск, заказы, Telegram, экспорт), `handlers/` — интерфейс бота, `data/niches.py` — каталог ниш, `db/` — SQLite (схема мигрирует автоматически).
