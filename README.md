# FindClient

Telegram-бот, который ищет клиентов на сайты и лендинги:

| Раздел | Что делает | Источники |
|---|---|---|
| 🔎 Компании с карт | Любая ниша × любой город (от Москвы до Урюпинска), фильтры «без сайта» / «с телефоном», фильтр живых точек (отзывов ≥ 2, в Москве ≥ 4), только мобильные номера, ЛПР из ЕГРЮЛ, слияние дублей между источниками, скоринг, выгрузка в XLSX/CSV | 2GIS (подписанный JSON API сайта 2gis.ru, запасной путь — парсинг страниц), Яндекс Карты (официальный API по ключу или веб-режим без ключа) |
| 💰 Денежные ниши | 39 ниш с оборотом компаний от миллионов ₽ в месяц: средний чек, зачем им сайт, запросы для карт, профильные Telegram-чаты | `data/niches.py` |
| 👷 Telegram-лиды | Строители, прорабы, дизайнеры, риелторы, спецтехника: авторы сообщений из профильных чатов (имя, @username, телефон, био, пример сообщения, скоринг) | Telethon (аккаунт пользователя) или публичные каналы через t.me/s |
| 💼 Заказы с бирж | Автоматически присылает новые заказы на сайты по ключевым и минус-словам | Kwork, FL.ru, Freelance.ru, FreelanceJob, Telegram-каналы, «нужен сайт» в чатах (с аккаунтом) |

Уже собранные компании при повторном поиске пропускаются (по id и по телефону), а историю можно скачать заново.

### Кого оставляет фильтр качества

- **Живые точки**: отзывов ≥ 2 (в Москве ≥ 4). Карточки-зомби с 0-1 отзывом
  выкидываются - туда писать незачем.
- **Достижимые контакты**: в колонке «Телефон» остаются только мобильные
  (+7 9...); городские (495/499/496...) и 8-800 срезаются. Компании
  выживают, если есть мобильный или мессенджер.
- **Мессенджер ★**: колонка «Мессенджер ★» - ссылка t.me/wa.me из карточки.
  Малый бизнес туда ссылку почти всегда оставляет сам хозяин: такие компании
  идут вверху списка и получают +10 к скорингу.
- **ЛПР (ЕГРЮЛ)**: ФИО руководителя из открытого ЕГРЮЛ/ЕГРИП (egrul.nalog.ru)
  по имени из карточки + регион. Для ИП ЛПР - сам предприниматель. Колонка
  заполняется в конце сбора (~1-2 с на компанию, 4 параллельных запроса);
  нет уверенного совпадения - остаётся пустой.
- **ИНН и «Выручка?»**: колонка «Выручка?» - ссылка на профиль компании на
  Rusprofile (выручка, штат, руководитель). Проверить оборот перед письмом -
  один клик.

## Запуск

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # впишите BOT_TOKEN и свой OWNER_IDS
python bot.py
```

Ваш Telegram ID бот покажет сам, если вас нет в `OWNER_IDS`.

### Переменные `.env`

| Переменная | Нужна | Описание |
|---|---|---|
| `BOT_TOKEN` | да | токен от @BotFather |
| `OWNER_IDS` | рекомендуется | ID пользователей через запятую; пусто — бот доступен всем |
| `YANDEX_API_KEY` | нет | ключ «API Поиска по организациям»; без него работает веб-режим |
| `HTTP_PROXY` | нет | прокси для Яндекса, если он начнёт показывать капчу |
| `TG_API_ID`, `TG_API_HASH`, `TG_SESSION` | нет | аккаунт Telegram для чтения групп (см. ниже) |
| `ORDERS_POLL_INTERVAL` | нет | период опроса бирж, секунды (по умолчанию 300) |

### Аккаунт Telegram (для групп строителей и поиска чатов)

Bot API не умеет читать чужие группы, поэтому для групп нужен пользовательский аккаунт:

1. Получите `api_id` и `api_hash` на https://my.telegram.org → API development tools.
2. `python scripts/tg_login.py`: введите телефон и код, скрипт напечатает `TG_SESSION=...`.
3. Добавьте три переменные в `.env` и перезапустите бота.

Используйте отдельный аккаунт. Чтение безопасно, а массовые рассылки из него быстро приводят к блокировке.
Без аккаунта раздел работает в урезанном режиме: собирает контакты из постов публичных каналов.

`/start` меню · `/scrape` поиск компаний · `/find стоматология | Казань | 100` быстрый поиск ·
`/niches` ниши · `/tg` Telegram-лиды · `/orders` заказы · `/history` · `/stats` · `/cancel`

## Ограничения

- **Avito**: блокирует серверные запросы (429), а официальный API не ищет чужие объявления. Рабочий путь — разместить своё объявление «Разработка сайтов» и подключить Messenger API (нужен бизнес-тариф). Не реализовано.
- **Хабр Фриланс** закрыт; **Weblancer** и **YouDo** закрыты антибот-защитой.
- Выручку компаний карты не отдают, а автоматом из открытых источников её не достать: бухгалтерская отчётность на bo.nalog.ru закрыта капчей, Rusprofile/Checko — антиботом. Поэтому «размер» оценивается косвенно (отзывы, филиалы, рейтинг — колонка «Скоринг»), а точную выручку по ИНН проверяйте по ссылке «Выручка?» (Rusprofile) перед письмом.
- Данные 2GIS и Яндекса предназначены для личного использования; не распространяйте выгрузки.

## Разработка

```bash
pytest -q        # ~1 с, без сети: внешние API замоканы (tests/conftest.py)
ruff check .     # линтер (конфиг в pyproject.toml)
```

Структура: `api/` — клиенты источников (контакты 2GIS — общий модуль `api/contacts.py`), `services/` — бизнес-логика (поиск, заказы, Telegram, экспорт), `handlers/` — интерфейс бота, `data/niches.py` — каталог ниш, `db/` — SQLite (схема мигрирует автоматически).

## CRM рассылки

Отдельное приложение в `crm/` — панель учёта клиентов, генератор офферов
(AI + правила) и воркер отправки с лимитами. Своя база `crm.db`, свои
systemd-юниты, в бот интегрирована одной кнопкой `/crm`. Подробности:
[crm/README.md](crm/README.md).

```bash
venv/bin/python -m crm.app      # панель (порт CRM_PORT, по умолчанию 8787)
venv/bin/python -m crm.sender   # воркер отправки
```

## Развёртывание

Всё живёт в `/opt/2gi_scraper`, venv — `venv`, сервис бота — `2gi-scraper.service`.

```bash
sudo bash deploy/deploy.sh               # установка с нуля (клон + venv + systemd)
sudo bash deploy/upgrade_2gi_scraper.sh  # апгрейд существующей установки с бэкапом
sudo bash deploy/preflight.sh            # проверка доступности источников с сервера
cd /opt/2gi_scraper && bash deploy/install_crm.sh   # CRM-панель и воркер
```
